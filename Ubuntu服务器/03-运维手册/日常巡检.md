## 3. Docker Healthcheck

```bash
for c in mall4cloud-mysql mall4cloud-redis mall4cloud-nacos \
         mall4cloud-mongo mall4cloud-elasticsearch metamcp metamcp-pg \
         1Panel-new-api-Mokn; do
  docker inspect -f '{{.Name}} {{.State.Health.Status}}' "$c"
done

cd /home/shadowdu/services/dify
for service in api db_postgres redis sandbox local_sandbox; do
  id=$(docker compose ps -q "$service")
  docker inspect -f '{{.Name}} {{.State.Health.Status}}' "$id"
done
```

## 6. 结果分级

| 级别 | 条件 | 动作 |
| --- | --- | --- |
| 🟢 正常 | 全部成功 | 记录核验时间 |
| 🟡 降级 | 单个非核心入口异常、主链路仍可用 | 查日志并计划恢复 |
| 🔴 故障 | 数据库/注册中心/消息链路不可用 | 停止依赖任务，执行 [[启停与恢复]] |
