## 核心链路

```text
Java Client -> Nacos API/gRPC
MySQL -> Canal -> RocketMQ -> Consumer -> Elasticsearch
Browser -> Gateway/Console -> Service
Browser -> Dify Nginx:12009 -> Web/API -> PostgreSQL/Redis/Weaviate
Client -> New API:3000 -> 上游模型渠道
```
