## Docker 数据位置

| 数据 | 路径 |
| --- | --- |
| Docker Root Dir | `/mnt/docker-data/docker` |
| containerd Root | `/mnt/docker-data/containerd` |
| containerd Runtime State | `/run/containerd` |
| Docker 命名卷 | `/mnt/docker-data/docker/volumes/<卷名>/_data` |

Docker 与 containerd 均配置了对机械盘的 systemd 挂载依赖。机械盘未挂载时服务不会启动，防止数据误写到系统盘。

## 关键配置

```text
/etc/fstab
/etc/docker/daemon.json
/etc/containerd/config.toml
/etc/systemd/system/docker.service.d/10-docker-data-mount.conf
/etc/systemd/system/containerd.service.d/10-docker-data-mount.conf
```

`/etc/docker/daemon.json` 的关键含义：

- `data-root` 必须保持为 `/mnt/docker-data/docker`。
- 镜像加速为 `https://docker.1panel.live/`。

## 检查命令

```bash
findmnt /mnt/docker-data
df -h / /mnt/docker-data
free -h
docker info --format '{{.DockerRootDir}}'
grep -E '^[[:space:]]*(root|state)[[:space:]]*=' /etc/containerd/config.toml
systemctl cat docker
systemctl cat containerd
```

预期 `/mnt/docker-data` 挂载到 `/dev/sdb3`，Docker Root Dir 为 `/mnt/docker-data/docker`。

## 变更注意

- 修改 Docker 配置时必须保留 `data-root`。
- 不要移除 `RequiresMountsFor=/mnt/docker-data`。
- 不要直接复制正在写入的数据卷目录作为唯一备份，参见 [[安全与备份]]。
