## Token 与签名密钥

### XXL-Job Executor

```text
XXL_JOB_TOKEN=mall4cloud_token
```

Java Executor 与 Admin 必须一致。

### WuKongIM

```text
WK_MANAGER_TOKEN=hn02le.34lkdLKD
JWT_SECRET=hn02le.34lkdLKD
JWT_EXPIRE=30d
```

Compose 将 `WK_MANAGER_TOKEN` 注入 `WK_MANAGERTOKEN`。

### Nacos Server Identity

```text
NACOS_AUTH_IDENTITY_KEY=mall4jmall4jmall4jmall4jmall4jmall4jmall4jmall4j123456
NACOS_AUTH_IDENTITY_VALUE=mall4cloudmall4cloudmall4cloudmall4cloudmall4cloudmall4cloudmall4cloud123456
```
