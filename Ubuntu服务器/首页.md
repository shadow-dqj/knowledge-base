## 推荐启动顺序

```text
机械盘挂载
  -> Docker / containerd
  -> MySQL、Redis、MongoDB、MinIO、Elasticsearch
  -> Nacos、RocketMQ Nameserver/Broker
  -> Seata、XXL-Job、Canal、WuKongIM、Dashboard
  -> MetaMCP、New API、Dify
  -> mall4cloud Java 服务（Provider 先于依赖它的 Consumer）
```

> [!warning] 动态状态
> `running` 只表示容器进程存在；没有 Docker healthcheck 的服务必须按各服务档案执行应用级验证。
