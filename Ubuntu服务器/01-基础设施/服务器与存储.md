## 数据路径

```text
Docker Root Dir     /mnt/docker-data/docker
containerd Root     /mnt/docker-data/containerd
containerd State    /run/containerd
Docker Volumes      /mnt/docker-data/docker/volumes
```

> [!danger] 挂载保护
> Docker 和 containerd 均依赖 `/mnt/docker-data`。机械盘未挂载时服务应拒绝启动，避免把新数据写入系统盘同名空目录。

## 关键配置

```text
/etc/fstab
/etc/docker/daemon.json
/etc/containerd/config.toml
/etc/systemd/system/docker.service.d/10-docker-data-mount.conf
/etc/systemd/system/containerd.service.d/10-docker-data-mount.conf
```

## 验证

```bash
findmnt /mnt/docker-data
df -h / /mnt/docker-data
docker info --format '{{.DockerRootDir}}'
systemctl cat docker containerd
```

> [!check] 成功判据
> `/mnt/docker-data` 来自 `/dev/sdb3`，Docker Root Dir 为 `/mnt/docker-data/docker`，Docker/containerd 为 active。

## 变更约束

- 保留 Docker `data-root` 和 containerd `root`。
- 保留两个 `RequiresMountsFor=/mnt/docker-data` drop-in。
- 不把运行中的卷目录文件复制当作唯一一致性备份。
